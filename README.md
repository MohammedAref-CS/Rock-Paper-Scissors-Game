# Rock Paper Scissors Game 🎮

A console-based Rock Paper Scissors game developed using C++.

## 📌 About the Project

This is a simple console game where the player competes against the computer in multiple rounds.

The computer randomly chooses Stone, Paper, or Scissors, and the program determines the winner of each round and the final winner of the game.

## 🎮 Game Choices

- 🪨 Stone
- 📄 Paper
- ✂️ Scissors

## ⚙️ Features

- Choose the number of rounds from 1 to 10.
- Player chooses Stone, Paper, or Scissors.
- Computer makes a random choice.
- Determines the winner of each round.
- Counts:
  - Player wins
  - Computer wins
  - Draws
- Displays the final game results.
- Changes the console color according to the round winner.
- Allows the player to play again.
